# Política de publicación segura

## Se publica

- Descripción ejecutiva de cada solución.
- Problema empresarial que resuelve.
- Módulos y capacidades verificables.
- Tecnologías utilizadas a nivel general.
- Capturas y videos con datos demostrativos.
- CV y credenciales profesionales seleccionadas.

## No se publica

- Código fuente de CRM, ERP, ventas, colegios, OCR o automatizaciones.
- Bases de datos, hojas operativas o respaldos.
- Usuarios, contraseñas, tokens, claves, IDs internos o archivos de configuración.
- Datos de clientes, cotizaciones, órdenes, recibos o documentos con información personal.
- Instaladores, paquetes de implementación ni archivos reutilizables del producto.
- Arquitectura detallada que facilite copiar o reconstruir la solución.

## Forma segura de demostrar

Las demos completas se presentan mediante videollamada, acceso temporal de solo lectura o sesión guiada. El repositorio público funciona como carta de presentación comercial y profesional.
